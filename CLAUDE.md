# RANKING DE VIDEOJUEGOS
Aolicacion web para mostrar un ranking de videojuegos e informacion de los mismos.
Es un proyecto educativo para aprender a usar Express, ejs, html5, CSS3 y JavaScript medio.

## ESPECIFICACIONES TÉCNICAS
- HTML 5
- CSS3
- Vanilla JavaScript (nada de angular, react,...)
- Maquetación unicamente con flex (nada de grid)
- Estructura del proyecto original
- Estructura del proyecto original con generate-express
- Plantilla EJS

## CONTENIDO

Usa contenido realista en inglés.
Las imágenes usalas desde https://picsum.photos

## BUENAS PRÁCTICAS

- Código en español
- Usa vanilla JavaScript siempre.
- Evita atributos de eventos
- Usar siempre classList
- Usar comentarios en plantillas
- Usar CSS anidado y variables cuando sea posible
